# Modojo promotional pitch deck

Generated presentation:

- `modojo-promotional-pitch-deck.pptx`

Generator:

- `../../scripts/create-pitch-deck.cjs`

Regenerate with:

```bash
npm run deck:generate
```

The deck uses the Modojo logo from `public/modojo_logo_wide.png` and includes a white logo variant for dark slides. It contains 14 slides and speaker notes for each slide.

The content is intentionally safe for early-stage promotion:

- product capabilities are based on the Modojo product documents
- dashboard and payment figures are labeled illustrative demo data
- pricing, traction, customer counts, revenue, testimonials, and investment asks remain placeholders until validated
- payment gateway capabilities are described as readiness/planned unless confirmed live

The deck can be used as a studio-owner sales presentation or adapted into an investor/Shark Tank presentation by replacing the final CTA and inserting validated business proof points.
